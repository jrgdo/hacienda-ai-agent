# Mapa de modelos candidatos

Este mapa sirve para formular preguntas, no para declarar automáticamente una obligación.

| Modelo | Tema general | Preguntas de aplicabilidad |
|---|---|---|
| 036 | Situación censal | ¿Alta, baja o modificación de actividad, local, régimen u obligaciones? |
| 111 | Retenciones del trabajo y profesionales | ¿Se pagaron nóminas o facturas profesionales con retención? |
| 115 | Retenciones de alquiler | ¿Se paga un alquiler sujeto a retención? |
| 130 | Pago fraccionado IRPF | ¿Actividad en estimación directa y sin exclusión aplicable? |
| 131 | Pago fraccionado por módulos | ¿Actividad en estimación objetiva? |
| 303 | Autoliquidación de IVA | ¿Operaciones sujetas y obligación periódica de IVA? |
| 349 | Operaciones intracomunitarias | ¿Entregas o adquisiciones/servicios intracomunitarios declarables? |
| 390 | Resumen anual de IVA | ¿Existe obligación anual o exoneración? |
| 180/190 | Resúmenes de retenciones | ¿Se presentaron los modelos periódicos correspondientes? |
| 347 | Operaciones con terceros | ¿Se alcanzan requisitos y no existe exclusión aplicable? |
| 100 | Declaración anual de Renta | ¿Cuál es el resultado anual completo y qué pagos previos se incorporan? |

Para cada modelo candidato, el agente debe consultar la ficha oficial del ejercicio, comprobar excepciones y explicar por qué se incluye o se descarta.

El modelo 037 fue suprimido con efectos de 3 de febrero de 2025. Solo debe tratarse como documentación histórica cuando corresponda. Comprobado el 5 de octubre de 2026 en [AEAT](https://sede.agenciatributaria.gob.es/Sede/ayuda/manuales-videos-folletos/manuales-practicos/manual-iva-2025/capitulo-01-novedades-destacar-2025/modelo-037.html).

Antes de usar este mapa, comprobar territorio común o foral. Canarias, Ceuta y Melilla, así como las haciendas forales, requieren rutas específicas y no deben resolverse aplicando automáticamente el IVA peninsular o modelos estatales.
