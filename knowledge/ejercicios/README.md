# Reglas por ejercicio

Crea una carpeta por ejercicio únicamente cuando las reglas hayan sido verificadas. Cada regla debe incluir:

- fecha de verificación;
- período de vigencia;
- URL oficial exacta;
- apartado consultado;
- resumen sin alterar los límites;
- pruebas afectadas;
- estado `verificada`, `provisional` u `obsoleta`.

No copies reglas de un ejercicio al siguiente sin volver a comprobarlas.
