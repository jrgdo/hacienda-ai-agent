# Espacio privado local

Guarda aquí el perfil, extractos, facturas, libros y declaraciones reales. Git ignora el contenido de esta carpeta.

Estructura sugerida:

```text
datos-usuario/
├── perfil.local.yaml
├── bancos/
├── facturas-emitidas/
├── facturas-recibidas/
├── plataformas/
├── declaraciones/
└── resultados/
```

No elimines ni renombres los documentos originales. Trabaja con copias derivadas dentro de `resultados/`.
